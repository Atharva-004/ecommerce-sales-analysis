# 📊 Excel Sales Dashboard

## 🔹 Overview

Interactive sales dashboard built in Microsoft Excel to analyze performance, trends, and key business metrics.

## 🔹 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts & Slicers

## 🔹 Features

* Dynamic and interactive dashboard
* Sales trend analysis
* Region-wise and category-wise performance
* KPI tracking with filters

## 🔹 Dashboard Preview

![Dashboard](dashboard.png)

## 🔹 Key Insights

* Identified top-performing regions and products
* Observed sales growth trends across months
* Highlighted high-revenue categories
